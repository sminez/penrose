Expand description

Quickly define a LayoutTransformer from a single element tuple struct and a transformation function: fn(Rect, Vec<(WinId, Rect)>) -> Vec<(WinId, Rect)>.

The struct must have a single field which is a Box<dyn Layout>.

§Example

fn my_transformation_function(r: Rect, positions: Vec<(WinId, Rect)>) -> Vec<(WinId, Rect)> {
    // transformation implementation goes here
    positions
}

simple_transformer!(MyTransformer, my_transformation_function, "MyTransform");
